# 2026-07-12 生图 Base64 异常计费修正

## 目标

修正 2026-07-11 12:50 至 2026-07-12 08:55（Asia/Shanghai）期间，旧生图链路将图片 Base64 数据带入后续 Responses 请求所产生的异常费用。

## 非目标

- 不退还正常的图片生成请求费用。
- 不修改模型正常文本请求的定价。
- 不冲销上游已经发生的实际成本。
- 不删除或改写原始用量记录。

## 识别规则

本次修正限定为修复上线前的异常窗口，并同时满足：

1. API 格式为 `openai:responses`；
2. 输入 Token 不少于 500,000；
3. 请求体超过审计系统的 256 KiB 保存上限；
4. 请求属于确认发生图片 Base64 回灌的 Codex 会话。

只读复核结果为 42 笔请求、5 个用户，原扣费合计 228.30407520 美元。其中充值余额扣除 152.41216165 美元，赠送余额扣除 75.89191355 美元，套餐额度扣除 0 美元。三项合计与原扣费完全一致。

## 数据修正

- 按每个钱包原扣除的余额类型分别恢复充值余额和赠送余额。
- 每个钱包写入一条固定事件编号的 `wallet_transactions` 调账记录，用于审计和防止重复退款。
- `wallets.total_adjusted` 增加相同金额；`total_consumed` 保留原始用量，形成“原扣费 + 修正调账”的完整账本。
- 原始 `usage`、`usage_settlement_snapshots` 和供应商成本记录保持不变，避免将用户补偿错误解释为供应商成本未发生。

## 影响范围

共涉及 5 个钱包。余额合计增加 228.30407520 美元，不影响其他用户、套餐额度、支付订单和供应商结算。
