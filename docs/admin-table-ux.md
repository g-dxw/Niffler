# 后台表格阅读与列宽调整

## 目标

- 后台高频表格在桌面端支持拖动列宽，管理员可以按当前排查任务看完整字段。
- 长字段不再只依赖省略号；拖宽后应能直接阅读，必要时保留 `title` 查看完整内容。
- 手机端优先使用已有卡片视图；没有卡片视图的表格至少保持横向滚动可用，不撑破页面。

## 非目标

- 不重做后台整体视觉风格。
- 不改变表格数据来源、筛选条件、排序规则和业务权限。
- 不把所有只读小表格强行改成复杂表格组件。

## 行为变化

- 号池管理、使用记录、用户管理、独立余额 API Key、提供商管理、钱包管理的主要桌面表格支持拖动表头右侧边缘调整列宽。
- 列宽保存在浏览器本地，同一页面再次打开时沿用上次宽度。
- 模型名、提供商链路、账号名、订单号、兑换码、备注等长字段改为可换行或可断词显示。

## 影响范围

- 仅影响管理后台前端展示和交互。
- 不修改后端接口、数据库结构、计费、调度、权限和生产数据。

## 验证方式

- 运行前端类型检查。
- 运行列宽拖动组合函数单元测试。
- 运行使用记录表格相关测试。
- 运行前端构建。
