# 号池主列表批量删除

## 目标

在号池管理主列表直接支持批量选择账号并删除，管理员不需要进入隐藏的批量操作弹窗才能完成删除。

## 非目标

- 不改变后端账号删除语义。
- 不新增数据库字段。
- 不调整号池调度、账号状态、额度刷新和账号导入逻辑。

## 行为变化

- 号池管理主列表增加账号选择框。
- 支持选择当前页账号，翻页后保留已选账号，便于跨页选择少量账号后统一删除。
- 切换提供商、搜索条件或状态筛选时清空选择，避免误删隐藏账号。
- 删除前显示确认框，明确提示删除数量和不可恢复。
- 删除使用现有 `POST /api/admin/pool/{providerId}/keys/batch-action`，`action=delete`。
- 删除完成后刷新账号列表和号池概览。

## 影响范围

- 前端号池管理页面。
- 通用 Checkbox 的半选显示。
- 号池批量删除任务状态读取兼容同步结果和后台任务结果。

## 验证方式

- 前端测试覆盖主列表勾选账号并批量删除。
- 运行号池管理相关前端测试。
- 运行前端类型检查。
