# 找回密码

## 目标

让本地账号用户可以通过邮箱重置密码，解决登录页没有找回密码入口的问题。

## 非目标

本次不支持 LDAP 账号和 OAuth 账号重置密码；不新增短信验证；不新增长期数据库表。重置令牌使用运行时 KV 存储，短期有效、一次性使用。

## 行为变化

登录弹窗提供“忘记密码”入口。用户提交邮箱后，如果邮件服务配置完整，系统返回统一成功文案，不暴露该邮箱是否存在。前端只能提示“申请已提交”，不能暗示一定发送成功。只有存在、启用、未删除、认证来源为 `local` 且有邮箱的账号会收到找回密码邮件。

找回密码申请复用邮箱发送冷却时间，避免同一邮箱短时间内反复创建重置令牌和邮件任务。冷却判断在查账号之前执行，因此存在邮箱和不存在邮箱在重复提交时表现一致。邮件模板渲染、令牌保存或邮件入队失败时，后端记录日志并继续返回统一成功文案，避免通过异常响应暴露账号是否存在。

找回密码邮件使用现有 `password_reset` 邮件模板，链接指向 `/reset-password?token=...`。令牌默认 30 分钟有效，只能使用一次。用户提交新密码后，后端按当前密码策略校验新密码；密码不符合策略时不消费令牌。密码校验通过后，后端消费令牌，并在同一个数据层操作里更新密码哈希和撤销该用户已有会话，避免出现密码已改但接口报失败的半成功状态。

## 影响范围

影响公开认证接口、邮件发送任务、登录弹窗、公开重置密码页面和前端认证 API。

## 验证方式

后端覆盖申请重置、创建邮件任务、弱密码不消费令牌、令牌重置密码、旧密码失效、新密码可登录。前端覆盖找回密码按钮和申请重置邮件入口，重置页通过类型检查覆盖。
