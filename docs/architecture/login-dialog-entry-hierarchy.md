# 登录弹窗入口层级

## 目标

重构登录弹窗的入口层级，让普通用户优先完成登录，让找回密码、注册、LDAP、OAuth、演示账号这些入口各自有清楚位置，避免同屏多个同权重按钮互相抢主任务。

## 非目标

本次不改变认证接口、不改变 OAuth/LDAP/本地登录能力、不重做注册弹窗，也不新增新的登录方式。

## 行为变化

登录弹窗只保留一个主标题和一个当前主操作。账号密码登录是默认主流程，OAuth 是登录方式的一部分，注册和找回密码是辅助入口。LDAP 只有在系统启用时展示，排他 LDAP 场景下管理员本地登录入口保留，但显示为轻量辅助操作。

找回密码使用同一弹窗内的二级面板，主操作变为“发送重置邮件”，返回登录是次级操作。发送成功后只显示必要结果，不再额外堆说明。

演示账号只在演示模式下展示，作为小型辅助区，不和正式登录入口同权重。

## 影响范围

影响 `LoginDialog.vue` 的页面结构、登录入口文案、按钮层级和相关组件测试。不影响后端登录、注册、OAuth、LDAP、找回密码接口。

## 验证方式

运行登录弹窗组件测试、前端类型检查和 UI 静态审查。组件测试覆盖标准登录表单、DOM 自动填充提交、找回密码入口和重置邮件申请。
