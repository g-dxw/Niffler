# 侧边栏余额与套餐摘要

## 目标

用户登录后，在主界面侧边栏底部直接看到当前可用额度、钱包余额、周期额度和套餐到期时间，减少进入钱包中心或套餐中心才能确认余额的操作。

## 非目标

- 不改变钱包、套餐和扣费规则。
- 不新增后端接口。
- 不展示用量单位数量；套餐仍按周期额度展示。

## 行为变化

- 桌面端在侧边栏底部账号区上方展示余额摘要。
- 移动端在展开菜单的用户信息上方展示同样的余额摘要。
- 余额摘要展示总可用额度、钱包余额、周期额度。
- 套餐到期时间展示当前有效套餐中最近到期的一份；没有到期时间时显示长期有效，没有有效套餐时显示未开通。
- 钱包余额和套餐权益分别加载；单个接口失败时只标记对应失败，并保留另一个接口的成功数据。
- 钱包中心或套餐中心加载到新数据后，会通知侧边栏刷新摘要。

## 字段来源

- 钱包余额来自 `/api/wallet/balance`。
- 套餐到期时间来自 `/api/billing/entitlements` 的 `expires_at`。
- 套餐口径为周期额度，按模型官方价格消耗，不按用量单位数量展示。

## 影响范围

- 仅影响登录后主布局的侧边栏和移动端菜单。
- 不影响后台钱包管理、套餐管理、结算和使用统计。

## 验证方式

- 检查前端类型引用和模板字段是否来自现有接口。
- 检查代码格式和补丁内容，不在本地执行完整编译。
