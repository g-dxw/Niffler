# 支付订单包含套餐购买

## 目标

管理后台的钱包订单页统一展示支付订单，包括钱包充值和套餐购买。管理员需要能直接看出每笔订单买的是什么，不能只看到金额和支付方式。

## 非目标

- 不改支付回调、到账和套餐发放的核心流程。
- 不调整套餐购买限制和价格计算规则。
- 不迁移历史数据。历史订单已经写入 `payment_orders`，本次只补齐查询和展示。

## 行为变化

- 管理接口返回订单类型、产品 ID、产品快照、发放状态和发放错误。
- 管理后台订单列表增加“订单内容”列。
- 管理后台订单列表支持按订单类型筛选：全部订单、钱包充值、套餐购买。
- 管理后台手动处理按钮按订单类型显示：钱包充值显示“确认到账”，套餐购买显示“确认发放”。

## 影响范围

- 后端钱包仓储的支付订单查询结构。
- 管理后台支付订单接口。
- 管理后台钱包页面的订单列表。
- 前端支付订单展示文案工具。

## 验证方式

- 后端测试覆盖管理订单列表和详情返回套餐购买字段。
- 前端工具测试覆盖订单内容文案。
- 运行管理后台钱包页面相关类型检查或测试。
