# 管理端使用记录按 Key 分组筛选

## 目标

管理端“使用记录”支持按用户 API Key 当前绑定的分组查询，方便排查某个产品策略或 Key 分组下的请求。

## 非目标

- 不改变使用记录写入、计费、钱包扣款和套餐扣除逻辑。
- 不按历史请求发生时的分组快照筛选；当前筛选语义是“这把 Key 现在绑定在哪个分组”。
- 不新增数据库表。

## 行为变化

- `/api/admin/usage/records` 新增可选查询参数 `api_key_group_id`。
- 管理接口先读取该分组下的 API Key ID，再把这些 Key ID 作为使用记录查询条件。
- 分页总数由后端按筛选条件统计，前端不做当前页二次筛选。
- 分组下没有 API Key 时，返回空列表和 `total = 0`。

## 影响范围

- 管理端使用记录列表。
- 认证读仓库新增按 Key 分组列出 API Key 的只读能力。
- 使用记录读仓库新增按 API Key ID 列表过滤的能力。

## 验证方式

- 后端测试覆盖 `/api/admin/usage/records?api_key_group_id=...` 只返回该 Key 分组下的请求。
- 前端测试覆盖管理端使用记录查询会传递 `api_key_group_id`。
